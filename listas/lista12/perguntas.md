## 2

## 3
    O HTTPS é um HTTP com mais proteção por conta da criptografia de dados.
## 4
    É quando um cliente interage com uma página. Nesse caso a página sendo o servidor.
    Criando uma relação em que o cliente faz uma HTTP Request (solicitação), o servidor
    processa e devolve uma HTTP Response (resposta).
## 5
    O método GET serve para trazer informações para o cliente, já o POST serve para 
    salvar informações no servidor.
## 6
